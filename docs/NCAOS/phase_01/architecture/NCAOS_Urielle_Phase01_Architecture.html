Architecture decision records
ADR-001 · docs/adr/ADR-001-type-contracts.md
Type contracts as architectural boundary
Zod-first schema; all packages import from @ncaos/core. Breaking changes require core version bump; new fields must be optional.
ADR-002 · docs/adr/ADR-002-fail-safe-invariant.md
Fail-safe default-deny invariant
Shell fails BLOCK/invalid on any error — unconditional. Cannot be disabled by policy. Process isolation noted for Phase 2. Chaos test scheduled Phase 6.
Key design invariants
EGS never modifies core model weights
The shell observes I/O only. Core is a structurally opaque black box. EGS cannot read activations, weights, or internal reasoning at any point.
Shell fails SAFE (deny) by default
ADR-002: any shell error → FAIL_SAFE verdict unconditionally. action=FAIL_SAFE, authority=invalid, score=0. Cannot be overridden by policy configuration.
No root-cause inference
EGS emits impact signals only — severity, scope, routing hints. No internal AI logic is exposed or inferred. IntegrityState carries a numeric score, not a root-cause explanation.
Evidence trail structurally independent of AI logs
Audit log is isolated from core. EVD handles use FNV hash of RID+timestamp. Phase 6 upgrades to HMAC-signed entries. Evidence archive in S3 is structurally separate from the AI runtime.
Tenant isolation enforced at type level
TenantContext (PARTNER_ID, INSTANCE_ID) scopes all governance state. Row-level security in DB. JWT scoping per tenant. Integration test suite validates isolation boundary.
