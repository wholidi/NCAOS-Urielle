Architecture decision records — new in Phase 02
ADR-003 · docs/adr/ADR-003-process-isolation.md
Process isolation invariant
EGS shell runs as a separate process from the AI runtime. A shared-process architecture risks a core crash disabling governance. Watchdog supervisor manages a 3-restart policy with exponential backoff. On restart exhaustion → permanent FAIL_SAFE (operator intervention required to revive). Chaos test scheduled for Phase 06. F-03 exposed this as a practical path-structure concern during testing.
