Architecture decision records — ADR-001 through ADR-004
ADR-001 · Phase 01
Zod-first type contracts as architectural boundary
All packages import from @ncaos/core. Breaking changes require version bump. New fields must be .optional().
ADR-002 · Phase 01
Fail-safe default-deny as unconditional invariant
failSafeVerdict() cannot be disabled by policy. Shell failure → BLOCK + authority=invalid + score=0. Chaos test Phase 06.
ADR-003 · Phase 02
Process isolation strategy
ShellLoop as separate process. Watchdog: 3-restart with exponential backoff (500→1000→2000ms). Permanent FAIL_SAFE on exhaustion.
ADR-004 · Phase 03
Detection layer independence
Each detector is a class, not a function. MTTD measured inside each detector using performance.now(). Rule sets configurable at construction. Per-tenant detector instances via TenantDetectorRegistry in Phase 04 (ADR-005).
